OpenAI(GPT) 키 만들기
  1. PC나 폰 브라우저에서 platform.openai.com 접속 → 로그인(ChatGPT 계정 사용 가능)
  2. Settings → Billing에서 카드를 등록하고 크레딧을 충전합니다(최소 $5). 자동 충전(auto recharge)은 끄는 것을 권장합니다.
  3. API keys → Create new secret key → 이름 입력 → 생성
  4. 나온 키(sk-로 시작)를 바로 복사합니다. 창을 닫으면 다시 볼 수 없습니다.
  5. 앱 설정 → OpenAI 키 칸에 붙여넣기 → 저장 → 연결 테스트

팁: Billing의 Usage limits에서 월 사용 한도를 정해 두면 예상보다 많이 나가는 일을 막을 수 있습니다.

Google Cloud 키 만들기
  1. console.cloud.google.com 접속 → 로그인 → 위쪽 프로젝트 선택 → 새 프로젝트
  2. 결제 메뉴에서 결제 계정을 연결합니다. 신규 가입 시 90일간 쓸 수 있는 $300 크레딧이 있습니다.
  3. API 및 서비스 → 라이브러리에서 Cloud Speech-to-Text API와 Cloud Translation API를 각각 검색해 사용을 누릅니다.
  4. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키
  5. 보안을 위해 키 제한: 애플리케이션 제한 = Android 앱(이 설정 화면에 나온 패키지 이름·SHA-1 입력), API 제한 = 위 두 API만
  6. 앱 설정 → Google 키 칸에 붙여넣기 → 저장 → 연결 테스트

팁: 결제 → 예산 및 알림에서 예산(예: 월 $5)을 정하면 그 금액에 가까워질 때 메일로 알려 줍니다.

키 관리 주의
  • 키는 비밀번호와 같습니다. 카톡·문자로 다른 사람에게 보내지 마세요.
  • 앱을 다른 사람에게 줄 때 키는 함께 가지 않습니다. 받는 사람은 자기 키를 넣어 씁니다.
  • 키가 노출된 것 같으면 OpenAI·Google 사이트에서 그 키를 삭제하고 새로 만드세요.
