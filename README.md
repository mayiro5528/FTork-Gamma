# FTalk (FriendlyTalk)

한국어 · 베트남어 · 영어 · 중국어 대화 통역 앱 (Android)

## 다운로드

**[최신 버전 APK 받기](https://github.com/mayiro5528/FTork-Gamma/releases/latest)**

1. 폰 브라우저에서 위 링크 → **Assets** 아래 `FTalk-v….-release.apk` 누르기
2. "출처를 알 수 없는 앱" 경고가 나오면 **이 출처 허용** → 설치
3. 처음 한 번은 Wi-Fi/데이터가 켜진 상태에서 앱을 열어 주세요. (번역 모델을 자동으로 받아요)

설치한 뒤에는 앱의 **설정 → 앱 정보 → 새 버전 받기** 로 업데이트할 수 있어요.

## 기능

| 기능 | 설명 |
|---|---|
| 눌러 말하기 | 내 쪽 / 상대방 쪽 마이크를 눌러 말하면 번역 |
| 실시간 대화 | Android 14 이상: 두 언어를 함께 듣고 누가 말해도 바로 번역 (기기 안 음성 데이터 자동 다운로드) · 그 밖의 폰: 두 언어를 번갈아 듣기 |
| 듣기 | 상대방 말만 계속 듣고 번역 (자동 읽기는 통화 스피커로) |
| 사진 | 카메라를 비추면 실시간 번역, 셔터를 누르면 원본·번역본을 사진 앱에 저장 |
| 계산기 | 사칙연산 계산기 + 원화 환산 (환율 자동) |
| 상황별 대화 | 여행 상황별 문장을 골라 크게 보여 주기 |

- 음성 인식: 폰의 Google 음성 인식 (Google 번역 앱과 같은 인식기)
- 번역: 기본은 **기기 번역(ML Kit, 무료, 오프라인)**. 자기 Google 키를 넣으면 **Google 서버 번역**(Google 번역 앱 온라인과 같은 품질)

## Google 서버 번역 쓰기 (선택 · 각자 자기 키)

키가 없어도 앱은 기기 번역으로 동작해요. 더 정확한 번역을 원하면 자기 키를 만들어 넣으세요.
키는 **그 폰 안에만** 저장되고, 요금은 **키를 만든 사람**에게 청구돼요. (매달 50만 자까지 무료, 그 뒤 100만 자당 약 $20)

1. PC에서 <https://console.cloud.google.com> 접속 → 로그인
2. 위쪽 프로젝트 선택 → **새 프로젝트**
3. **결제** 메뉴에서 결제 계정(카드) 연결
4. **API 및 서비스 → 라이브러리** → `Cloud Translation API` 검색 → **사용**
5. **사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키** → 키(`AIza…`) 복사
6. (권장) 만든 키를 눌러서
   - **애플리케이션 제한사항: Android 앱** → 항목 추가
     - 패키지 이름: `com.ftork.gamma`
     - SHA-1 인증서 지문: `86:29:AF:55:D7:DE:9C:76:FC:31:3F:43:FC:F9:9C:5F:07:2C:D1:07`
   - **API 제한사항: 키 제한** → `Cloud Translation API` 만 체크 → 저장
7. 앱 **설정 → 음성 인식·번역 엔진 → Google** 선택 → 키 붙여넣기 → **저장** → 5분 뒤 **연결 테스트**

"연결 성공"이 나오면 대화 · 사진 · 실시간 카메라 번역이 모두 Google 번역으로 바뀌어요.
앱 설정 화면에도 같은 안내와 패키지 이름 · SHA-1 **복사 버튼**이 있어요.

### 연결 테스트가 실패할 때

| 메시지 | 해결 |
|---|---|
| 다른 앱 전용으로 제한돼 있어요 (`Requests from this Android client application … are blocked`) | 6번의 패키지 이름 · SHA-1 을 키 제한에 추가 |
| Cloud Translation API 가 꺼져 있어요 | 4번: 라이브러리에서 Cloud Translation API **사용** |
| 결제 계정이 연결되지 않았어요 | 3번: 결제 계정 연결 |
| Cloud Translation API 를 쓸 수 없게 제한돼 있어요 | 6번: API 제한사항에 Cloud Translation API 체크 |
| 키가 올바르지 않아요 | 키를 다시 복사해서 붙여넣기 |

설정을 바꾼 뒤 적용까지 몇 분 걸릴 수 있어요.
